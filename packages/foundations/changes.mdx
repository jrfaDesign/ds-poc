# Color System Changes

## 1. Base Colors

The base palette includes the following non‑scalable tokens:

- white
- black
- transparent

These tokens do **not** follow numeric scales.

---

## 2. Color Scales

All scalable color families MUST follow this numeric ramp:

50, 100, 200, 300, 400, 500, 600, 700, 800, 900, 950

Applicable to:

- neutral
- primary
- secondary
- primary_accent (optional)
- secondary_accent (optional)
- any future optional families

---

## 3. Mandatory & Optional Color Families

### Mandatory (required for theme creation)

- neutral
- primary
- secondary

### Optional (fallback to default theme)

- primary_accent
- secondary_accent
- semantics
- any future optional families

---

## 4. Theme Creation API

We already have an internal function `mergeTheme()` that merges a theme configuration with the default theme. However, we need to enforce mandatory families and allow optional families to fallback to default values.
We introduce a new function: `createTheme(themeConfig)`.

### Requirements

- `themeConfig` MUST include:
  - `neutral`
  - `primary`
  - `secondary`

- `themeConfig` MAY include:
  - `primary_accent`
  - `secondary_accent`
  - other optional families

- Any missing optional families MUST fallback to the default theme token values (if they exist, primary_accent does not exist in the default, but semantic already does.).

- `createTheme()` MUST validate mandatory families before internally calling `mergeTheme()`.

# Typography System

A unified typography system with scale tokens, semantic variants, and a flexible component API.

---

## 1. Scale Tokens

Each scale token bundles font size and optional letter spacing in both px and rem.

| Token | fontSizePx | fontSizeRem | letterSpacing |
| ----- | ---------- | ----------- | ------------- |
| `6xl` | 72         | 4.5         | -0.02         |
| `5xl` | 60         | 3.75        | -0.02         |
| `4xl` | 48         | 3           | -0.02         |
| `3xl` | 36         | 2.25        | —             |
| `2xl` | 30         | 1.875       | —             |
| `xl`  | 24         | 1.5         | —             |
| `lg`  | 20         | 1.25        | —             |
| `md`  | 18         | 1.125       | —             |
| `sm`  | 16         | 1           | —             |
| `xs`  | 14         | 0.875       | —             |
| `xxs` | 12         | 0.75        | —             |

## 4. Semantic Variants (Contracts)

Each semantic variant is a preset that composes tokens into a complete typographic style. Variants are mapped to HTML tags and ARIA attributes automatically.

| Role       | fontSize     | fontWeight       | lineHeight     | fontFamily | letterSpacing      | color          | HTML Tag | ARIA                            |
| ---------- | ------------ | ---------------- | -------------- | ---------- | ------------------ | -------------- | -------- | ------------------------------- |
| `h1`       | `6xl` (72px) | `bold` (700)     | `normal` (1.5) | `heading`  | `tight` (-0.025em) | `text-primary` | `<h1>`   | `role="heading" aria-level="1"` |
| `h2`       | `5xl` (60px) | `bold` (700)     | `normal` (1.5) | `heading`  | `tight` (-0.025em) | `text-primary` | `<h2>`   | `role="heading" aria-level="2"` |

## 5. Component Props

### Tailwind (`@repo/ui-web-tailwind`)

| Prop            | Type                          | Default     | Description                                                           |
| --------------- | ----------------------------- | ----------- | --------------------------------------------------------------------- |
| `role`          | `TypographyRole`              | `'p'`       | Semantic preset — applies CSS class + sets HTML tag + ARIA attributes |
| `size`          | `FontSizeToken`               | (from role) | Override font-size scale token                                        |
| `weight`        | `CSSProperties['fontWeight']` | (from role) | Override font weight                                                  |
| `lineHeight`    | `LineHeightToken`             | (from role) | Override line-height scale token                                      |
| `letterSpacing` | `LetterSpacingToken`          | (from role) | Override letter-spacing scale token                                   |
| `color`         | `TypographyColor`             | (from role) | Override text color token                                             |
| `as`            | `TypographyTag`               | (from role) | Override HTML element                                                 |
| `invert`        | `boolean`                     | `false`     | Flip light/dark mode for this subtree                                 |
| `className`     | `string`                      | —           | Additional CSS classes                                                |
| `style`         | `CSSProperties`               | —           | Inline style overrides                                                |
| `children`      | `ReactNode`                   | (required)  | Text content                                                          |

### StyleX (`@repo/ui-web-stylex`)

| Prop            | Type              | Default     | Description                                                             |
| --------------- | ----------------- | ----------- | ----------------------------------------------------------------------- |
| `role`          | `TypographyRole`  | `'p'`       | Semantic preset — applies StyleX rule + sets HTML tag + ARIA attributes |
| `size`          | `string`          | (from role) | Override font-size via CSS var                                          |
| `weight`        | `string`          | (from role) | Override font weight via inline style                                   |
| `lineHeight`    | `string`          | (from role) | Override line-height via CSS var                                        |
| `letterSpacing` | `string`          | (from role) | Override letter-spacing via CSS var                                     |
| `color`         | `TypographyColor` | (from role) | Override text color token                                               |
| `children`      | `ReactNode`       | (required)  | Text content                                                            |

## 6. Override Rules

1. **`role` applies a preset** — selects a CSS class (Tailwind: `type-h2`, StyleX: pre-built rule) that sets font-size, font-weight, line-height, letter-spacing, and color from the contract.

2. **Individual props override the preset** — `size`, `weight`, `lineHeight`, `letterSpacing` are applied as inline styles / CSS vars that take precedence over the preset class.

3. **If `role` is omitted** — no preset class is applied. The component uses pure token mode (you must provide `size` and `weight` or accept browser defaults).

4. **`as` always overrides the HTML element** — regardless of role. The ARIA attributes still follow the original `role`.

---

## 7. Usage Examples

### Semantic only (preset)

```tsx
<Typography role="h2">Section Title</Typography>
```

### Semantic + overrides

```tsx
<Typography role="h2" size="lg" weight="medium">
	Custom heading
</Typography>
```

### Token-only (no role preset)

```tsx
<Typography size="2xl" weight="bold" lineHeight="normal">
	Free-form text
</Typography>
```

### With color override

```tsx
<Typography role="p" color="text-secondary">
	Muted paragraph
</Typography>
```

### Override HTML element

```tsx
<Typography role="h2" as="span">
	Heading rendered as span
</Typography>
```

## 8. Architecture

```
┌─────────────────────────────────────────────────────────────┐
│                    Component API                              │
│  role (preset) + size/weight/lineHeight/ls (override)        │
└───────────────────────┬─────────────────────────────────────┘
                        │
┌───────────────────────▼─────────────────────────────────────┐
│              Semantic Contracts (Presets)                     │
│  h1 → { fontSize: 6xl, weight: bold, lh: normal, ff: heading }│
│  h2 → { fontSize: 5xl, weight: bold, lh: normal, ff: heading }│
│  ...                                                         │
└───────────────────────┬─────────────────────────────────────┘
                        │ resolves to
┌───────────────────────▼─────────────────────────────────────┐
│              Scale Tokens (Primitives)                        │
│  6xl → { fontSizePx: 72, fontSizeRem: 4.5, ... }            │
│  bold → 700                                                  │
│  normal → 1.5                                                │
│  heading → "Font Name", system-ui, sans-serif                 │
└─────────────────────────────────────────────────────────────┘
```

**Key principle:** Semantic variants are presets built on top of scale tokens. There is no duplication — every contract references token keys, never raw values.
